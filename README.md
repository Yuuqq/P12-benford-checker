## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅱ 方法篇 · 第5章 新闻数据的获取与管理**（教材 Tier 1 实验工具）。教材命名："本福特定律检测仪"。

**学习目标**：理解本福特定律的内容与适用条件，能用首位数字分布检验发现数据中的异常迹象，体会统计方法在数据监督报道中的作用与边界。

**核心术语**：本福特定律（Benford's Law）、首位数字分布（First-digit Distribution）、异常检测（Anomaly Detection）

**适合对象**：新闻传播专业学生、数据新闻初学者、事实核查爱好者

**课前准备**：课前领取教师提供的两组数值数据（一组真实、一组人为编造），或自备一份 200 个数值以上的公开数据 CSV；本工具打开即用、离线可用。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师导入一份真实财政或经济数据并点击"开始分析"，结合"分布对比"图讲解"1 开头约占三成"的反直觉规律与实际/理论分布的读图方法
2. **上手实操**（20 分钟）：学生按教材实验步骤完成：①分别导入真实组与编造组数据并分析；②记录两组的实际分布、偏离度与提示结论；③自己再编一组"首位数字均匀分布"的假数据，验证检测灵敏度；④留意工具对样本量过小的提示，讨论最小样本量问题；⑤填写实验记录表，给出"哪组数据可疑"的判断与理由
3. **小组讨论**（8 分钟）：某单位报销单据的首位数字分布偏离本福特定律，能否直接断定造假？报道前还需要哪些佐证？
4. **总结**（4 分钟）：本福特检验是"嗅探器"不是"判决书"，偏离只是立案调查的起点

**课后作业**：自选一份公开数据（不少于 200 个数值）完成本福特检验，提交分布对比截图、偏离度数据与 300 字判读短文

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。
